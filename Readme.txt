# Journifi AI — Release Channel

This repository hosts the binary releases for [Journifi AI](https://github.com/ShredSteezy/JournifiAI).

The actual application source code is in a separate private repository. This repo exists purely
as a public distribution channel that the in-app auto-updater fetches from.

## Installation

Download the latest installer from the [Releases page](../../releases/latest).

## Auto-updates

Once installed, Journifi AI checks this repository for new versions on launch (and every 4 hours)
and downloads them in the background. You'll see a "Restart to install" toast when an update is ready.
